# 5G — หมวดหมู่ + ผู้จัดจำหน่าย (app.js 846-1036)

> [← ภาพรวม](00-overview.md) · โค้ด: [../frontend/app.js:846](../frontend/app.js) · คู่กับ backend [4D](../study-index-js/4D-categories.md) [4E](../study-index-js/4E-suppliers.md) · **โครงเหมือนสินค้าทุกอย่าง**

## หมวดหมู่ (846-927)

| บรรทัด | ฟังก์ชัน | endpoint |
|---|---|---|
| 851 | `loadCategories` วาดตาราง (ชื่อ, คำอธิบาย, "N ชิ้น", ปุ่มรายละเอียด/แก้ไข/ลบ) + เติมเมนูกรอง | `GET /categories` (854) |
| 890 | `openCategoryForm(c)` 2 ช่อง: ชื่อ (บังคับ), คำอธิบาย | `POST` / `PATCH /categories/:id` (903) |
| 913 | `deleteCategory(c)` **เตือน "⚠️ สินค้า N ชิ้นในหมวดนี้จะถูกลบไปด้วย"** (CASCADE) | `DELETE /categories/:id` (917) |

## ผู้จัดจำหน่าย (929-1036)

| บรรทัด | ฟังก์ชัน | endpoint |
|---|---|---|
| 934 | `loadSuppliers` (ชื่อ, รหัส, อีเมล, เบอร์, "N ชิ้น", ปุ่ม) | `GET /suppliers` (937) |
| 975 | `openSupplierForm(s)` 4 ช่อง: ชื่อ, อีเมล (ตรวจรูปแบบ 989), เบอร์ (ตรวจ 995), รหัส (เพิ่มเว้นว่างได้ → `SUP-` + เวลา) | `POST` / `PATCH /suppliers/:id` (1013) |
| 1023 | `deleteSupplier(s)` **เตือน "สินค้า N ชิ้นจะเปลี่ยนเป็นไม่มีผู้จัดจำหน่าย (สินค้าไม่ถูกลบ)"** (SET NULL) | `DELETE /suppliers/:id` (1027) |

## ปุ่ม "รายละเอียด" (ทั้งสองแท็บ)
`detailCell` (663) → `openCategoryDetail` (687) / `openSupplierDetail` (701) → ป๊อปอัปแสดงข้อมูล + **รายการสินค้าที่เกี่ยวข้อง** กรองจาก `state.products` ไม่ยิง API · ทุกคนเห็นปุ่มนี้ (ไม่ใช่ admin-only)

## หลังเพิ่ม/แก้/ลบ โหลดอะไรใหม่
- แก้ชื่อหมวดหมู่/ผู้จัดจำหน่าย → โหลดสินค้าใหม่ด้วย (ชื่อในตารางสินค้าต้องเปลี่ยนตาม)
- ลบหมวดหมู่ → โหลดทั้ง 3 ตาราง (สินค้าบางชิ้นหายไป)

## 🎯 คำถามที่อาจารย์น่าถาม

| คำถาม | คำตอบ |
|---|---|
| **หน้าเว็บรู้ได้ไงว่าลบแล้วกระทบสินค้ากี่ชิ้น** | ใช้ `product_count` ที่ backend นับให้ด้วย `COUNT` + `GROUP BY` แทรกลงข้อความยืนยัน |
| **ทำไมข้อความเตือนลบสองแท็บต่างกัน** | หมวดหมู่ใช้ CASCADE (สินค้าหาย) ผู้จัดจำหน่ายใช้ SET NULL (สินค้าอยู่ต่อ) ตามที่ตั้งใน `schema.sql` |
| **ปุ่มรายละเอียดยิง API ไหม** | ไม่ ใช้ข้อมูลใน `state` ที่โหลดไว้แล้ว |
