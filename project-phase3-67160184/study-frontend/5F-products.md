## โหลดและวาดตาราง (469-524)
```
470  ครั้งแรก → "กำลังโหลดข้อมูล..."
472  fetch GET /products   (GET ไม่ต้อง token ใช้ fetch ธรรมดา)
474  เก็บใน state.products → renderProducts
476  พัง → แถวแดง + ปุ่มลองใหม่
485  renderProducts: สร้าง <tr> ทีละสินค้า (ชื่อ, SKU, หมวด, ผู้จัดจำหน่าย, ราคา, "N ชิ้น", ปุ่ม)
508  แปะข้อความค้นหาไว้ในแถว (data-search) ไว้กรอง
517-522  แถวที่เพิ่งเพิ่ม/แก้ → เลื่อนให้เห็น + ไฮไลต์ฟ้าจางใน 3 วินาที
```

## แสดงราคาเป็น USD/EUR/JPY ทั้งตาราง (526-589)
```
551  setDisplayCurrency(code) → ขออัตรา 1 ครั้ง ผ่านสินค้าชิ้นแรก (566)
533  priceCell: ราคา × อัตรา ปัด 2 ตำแหน่ง (สูตรเดียวกับ backend) → ทุกแถว
     ผิดพลาด / API fallback → คงสกุลเดิม + ข้อความแดง
```
**ทำไมไม่ยิงทีละสินค้า:** แต่ละครั้ง backend ไปถาม API ภายนอก 10 สินค้า = 10 ครั้ง ช้าและเสี่ยงโดนจำกัดการเรียก ขอครั้งเดียวแล้วคูณเองเร็วกว่า ตรวจแล้วตรงกับ backend 30/30

- **`displaySeq` (529, 569)**: กันคำตอบเก่าที่มาช้าทับผลใหม่ เมื่อกดสลับสกุลรัวๆ (race condition)
- (2026-10-30 เอาปุ่ม "แปลงราคา" รายแถวและป๊อปอัปของมันออกแล้ว เพราะซ้ำกับแถบนี้)

## ค้นหา + กรอง (590-653)
- `filterRows` (592) ซ่อนแถวที่ไม่ตรงคำค้น ใช้ร่วมกับเมนูกรองหมวดหมู่/ผู้จัดจำหน่าย (`matches`)
- **ไม่ยิง API** กรองข้อมูลที่โหลดมาแล้วใน `state` · แสดง "พบ X จาก Y รายการ"
- `fillFilterOptions` (629) เติมรายการในเมนูกรองจากข้อมูลจริง ถ้ารายการที่เลือกถูกลบ กลับเป็น "ทั้งหมด"

## ฟอร์มเพิ่ม/แก้ไข (737-828)
- `productFields(isEdit)` (737): ชื่อ, SKU (ตอนเพิ่มเว้นว่างได้ ระบบสร้าง), ราคา > 0, สต็อก ≥ 0, หมวดหมู่, ผู้จัดจำหน่าย (บังคับเสมอ) — dropdown มาจาก `state.categories` / `state.suppliers` (ข้อมูลจริง)
- `openProductForm(p)` (787): ไม่ส่ง `p` = เพิ่ม (POST) · ส่ง `p` = แก้ไข (PATCH) บรรทัด 818 เลือกให้
- แปลงค่าเป็นตัวเลขก่อนส่ง (`Number(...)`) เพราะค่าจากช่องกรอกเป็นข้อความเสมอ
- สำเร็จ → toast + โหลดตารางใหม่ + ไฮไลต์แถว + โหลดหมวดหมู่/ผู้จัดจำหน่าย (ตัวเลข "N ชิ้น" อัปเดต)

## 🎯 คำถามที่อาจารย์น่าถาม

| คำถาม | คำตอบ |
|---|---|
| **ค้นหายิง API ไหม** | ไม่ กรองในเบราว์เซอร์จาก `state` ข้อมูลหลักร้อยพอ ถ้าหลักพันต้องย้ายไปค้นที่ backend |
| **แปลงราคาทั้งตารางทำยังไง** | ขออัตราครั้งเดียว แล้วคูณราคาทุกแถวด้วยสูตรเดียวกับ backend |
| **ป๊อปอัปเพิ่มกับแก้ไขเป็นอันเดียวกันไหม** | ใช่ `openProductForm` ตัวเดียว ดูว่ามีสินค้าส่งมาไหมแล้วเลือก POST/PATCH |
| **dropdown หมวดหมู่มาจากไหน** | `GET /categories` ที่โหลดเก็บใน `state.categories` (ไม่ใช่ค่าตายตัว) |
| **กดลบแล้วเกิดอะไร** | `confirm` ยืนยัน (832) → `DELETE /products/:id` → toast → โหลดตารางใหม่ |
