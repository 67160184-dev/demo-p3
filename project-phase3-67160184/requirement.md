# เอกสาร Requirement Specification
**ชื่อโครงงาน:** ระบบบริหารจัดการข้อมูลสินค้าและคลังสินค้า (Product & Inventory Management System)  
**รหัสนิสิต:** 67160184 | **ระบบลำดับที่:** P5 (ระบบข้อมูลสินค้า)

---

## 1. ชื่อระบบและวัตถุประสงค์
* **ชื่อระบบ:** StockPro - Product Management Backend Service
* **วัตถุประสงค์:** เพื่อพัฒนาระบบหลังบ้านสำหรับจัดการข้อมูลสินค้า หมวดหมู่สินค้า และผู้จัดจำหน่าย (Supplier) อย่างมีประสิทธิภาพ แก้ไขปัญหาข้อมูลสินค้าซ้ำซ้อน การจัดหมวดหมู่ที่ไม่เป็นระบบ และตรวจสอบจำนวนสินค้าคงคลังที่ไม่แม่นยำ
* **กลุ่มผู้ใช้เป้าหมาย:**
  1. **ผู้ดูแลระบบ (Admin):** จัดการข้อมูลหมวดหมู่สินค้าและข้อมูลผู้จัดจำหน่าย
  2. **เจ้าหน้าที่คลังสินค้า (Inventory Staff):** เพิ่ม/แก้ไขข้อมูลสินค้า ตรวจสอบ SKU และอัปเดตจำนวนสินค้าคงคลัง

---

## 2. รายการ Use Case หลัก (5 Use Cases)
1. **UC-01: เพิ่มหมวดหมู่สินค้าใหม่ (Create Category)**
   * **ผู้ใช้งาน:** Admin
   * **รายละเอียด:** สามารถสร้างหมวดหมู่สินค้าใหม่ เช่น Electronics, Apparel เพื่อใช้นำกลุ่มสินค้า
2. **UC-02: เพิ่มข้อมูลผู้จัดจำหน่าย (Create Supplier)**
   * **ผู้ใช้งาน:** Admin
   * **รายละเอียด:** บันทึกข้อมูลบริษัทผู้ผลิต/จัดจำหน่าย พร้อมรหัสผู้จัดจำหน่าย (Supplier Code) และข้อมูลติดต่อ
3. **UC-03: เพิ่มข้อมูลสินค้าใหม่ (Create Product)**
   * **ผู้ใช้งาน:** Inventory Staff
   * **รายละเอียด:** เพิ่มสินค้าเข้าสู่ระบบ โดยกำหนดชื่อ, ราคา, รหัส SKU (ต้องไม่ซ้ำกัน), เชื่อมโยงกับ Category และ Supplier
4. **UC-04: เรียกดูรายการสินค้าทั้งหมดพร้อมรายละเอียด (View Products with Details)**
   * **ผู้ใช้งาน:** Admin / Inventory Staff
   * **รายละเอียด:** ดึงข้อมูลรายการสินค้าแบบ JOIN เพื่อแสดงชื่อสินค้า, ราคา, SKU, หมวดหมู่ และผู้จัดจำหน่ายใน Query เดียว
5. **UC-05: อัปเดตราคาสินค้าและจำนวนคงคลัง (Update Price & Stock)**
   * **ผู้ใช้งาน:** Inventory Staff
   * **รายละเอียด:** แก้ไขราคาสินค้า หรือปรับปรุงจำนวนสินค้าคงคลัง (Stock Quantity) ตามการตรวจนับจริง

## 3. รายการ Resource หลักและความสัมพันธ์ (Resources & Relationships)
ระบบประกอบด้วย 3 Resource หลัก ได้แก่:

1. **`categories` (หมวดหมู่สินค้า):** ตารางเก็บข้อมูลหมวดหมู่
2. **`suppliers` (ผู้จัดจำหน่าย):** ตารางเก็บข้อมูลคู่ค้า/ผู้ผลิตสินค้า
3. **`products` (รายการสินค้า):** ตารางหลักเก็บรายละเอียดสินค้า เช่น `name`, `price`, `sku`, `stock_quantity`

### ความสัมพันธ์ระหว่าง Resource:
* **`categories` (1) — (N) `products` (One-to-Many):**
  * หมวดหมู่ 1 หมวดหมู่ สามารถมีสินค้าได้หลายรายการ
  * หากลบหมวดหมู่ สินค้าในหมวดหมู่นั้นจะถูกลบไปด้วย (`ON DELETE CASCADE`)
* **`suppliers` (1) — (N) `products` (One-to-Many):**
  * ผู้จัดจำหน่าย 1 ราย สามารถส่งสินค้าได้หลายรายการ
  * หากลบผู้จัดจำหน่าย ข้อมูลสินค้าจะยังอยู่ แต่เปลี่ยน `supplier_id` เป็น NULL (`ON DELETE SET NULL`)
