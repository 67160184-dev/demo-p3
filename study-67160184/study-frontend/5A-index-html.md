## frontend มี 3 ไฟล์ แบ่งหน้าที่ชัด

| ไฟล์ | หน้าที่ | เปรียบเหมือน |
|---|---|---|
| `index.html` | **มีอะไรบนหน้า** (ปุ่ม ตาราง ป๊อปอัป) | โครงบ้าน |

## 🎯 คำถามที่อาจารย์น่าถาม

| คำถาม | คำตอบ |
|---|---|
| **ทำไมแยก CSS เป็น `style.css`** | แยกหน้าที่ให้ชัด: HTML = โครง, CSS = หน้าตา, JS = การทำงาน แก้หน้าตาไม่ต้องยุ่งกับโครง และเบราว์เซอร์จำไฟล์ CSS ไว้ใช้ซ้ำได้ (cache) |
| **ซ่อนปุ่มด้วย CSS ปลอดภัยไหม** | ไม่ใช่ความปลอดภัย เป็นแค่ UX ความปลอดภัยจริงคือ backend ตรวจ JWT (`requireAdmin`) ทุก POST/PATCH/DELETE |
| **ทำไม `<link>` อยู่บน แต่ `<script>` อยู่ล่าง** | CSS ต้องโหลดก่อนแสดงหน้า ไม่งั้นหน้าจะกระพริบไม่มีสี ส่วน JS ต้องรอให้ element ทั้งหมดมีอยู่ก่อน |
| **ฟอร์มเดียวใช้หลายแบบได้ไง** | `#form-dialog` เป็นกรอบว่าง app.js สร้างช่องกรอกใหม่ทุกครั้งที่เปิด (ดู [5D](5D-openForm.md)) |

## 🌐 ลองดูเอง
- http://localhost:3000/style.css → เห็นไฟล์ CSS (ส่งมาจาก `express.static`)
- F12 → Network → รีเฟรช → เห็นเบราว์เซอร์โหลด 3 ไฟล์: `localhost` (index.html), `style.css`, `app.js` แล้วตามด้วยคำขอ API
- ⚠️ ถ้าแก้ CSS แล้วหน้าไม่เปลี่ยน กด **Ctrl+F5** (เบราว์เซอร์จำไฟล์เก่าไว้)
