## 🎯 loading/error ครบตามเกณฑ์ (3 คะแนน)

| สถานการณ์ | ผู้ใช้เห็น | โค้ด |
|---|---|---|
| กำลังโหลดตาราง | "กำลังโหลดข้อมูล..." | `messageRow` (48) เรียกจาก `loadProducts` (469) |
| โหลดไม่สำเร็จ (DB ล่ม / server ปิด) | แถวแดงบอกสาเหตุ + ปุ่ม "↻ ลองใหม่" | `messageRow(..., "error", retry)` |
| กำลังบันทึก / เข้าสู่ระบบ | "กำลังบันทึก..." ปุ่มบันทึกกดไม่ได้ | `openForm` (313-315) |
| บันทึกไม่สำเร็จ | ข้อความแดงในป๊อปอัป ป๊อปอัปไม่ปิด | `openForm` (319-321) |
| กำลังลบ | toast "กำลังลบ..." | `deleteRequest` (458) |
| สำเร็จ | toast สีเข้ม ✓ + แถวไฮไลต์ฟ้า | `toast` (34) |
| แถบ "แสดงราคาเป็น" กำลังดึง / ผิดพลาด | "กำลังดึงอัตราแลกเปลี่ยน..." / ข้อความแดง คงสกุลเดิม | `setCurrencyNote` (546) |

## 🎯 คำถามที่อาจารย์น่าถาม
- **ถ้าเซิร์ฟเวอร์ล่ม หน้าเว็บเป็นยังไง?** → ไม่ค้างเงียบ แถวแดงบอก "เชื่อมต่อเซิร์ฟเวอร์ไม่ได้..." พร้อมปุ่มลองใหม่ (`errorText` 10 + `messageRow` 48)
- **ทำไมใช้ `textContent` ไม่ใช้ `innerHTML`?** → กัน XSS ถ้ามีคนตั้งชื่อสินค้าเป็นโค้ด `<script>` จะแสดงเป็นข้อความเฉยๆ ไม่ถูกรัน
- **`state` คืออะไร?** → ที่เก็บข้อมูลล่าสุดในเบราว์เซอร์ ทำให้ค้นหา/กรองได้ทันทีโดยไม่ยิง API

## 🌐 ลองดูเอง
